# 1.3.0 动态配色、图数预算与组合图门槛

> 历史说明：其中“最多3面板”的固定数量规则已在 1.4.0 撤销。当前规则由 GPT-5.6 Sol 按共同读者问题、共同视觉角色、联合扫读必要性和正文栏宽可读性决定，确定性层不再设置固定面板上限。

## 升级结论

本版解决三个会影响正式落地的设计缺口：MCP 过去只校验色板 ID 而未把审美平台的视觉语义交给设计模型；图数只有 30 页版面提醒而没有 20 图级的全文预算；分面模板没有明确的组合必要性门槛和最多 3 面板限制。

## 动态读取可视化审美平台

- 唯一色板来源为 `可视化审美研究/studio/data/palettes.json`，MCP 不复制、冻结或另建色板名单。
- 每次构建设计包时实时传入 `palette_id`、中英文名、类型、描述、语义标签、背景色、墨色、强调色位置以及各颜色的 HEX 与角色。
- 本地先根据图形语义生成候选排序，GPT-5.6 Sol 再结合完整色板和前端审美进行选择。
- 热力图、偏差矩阵、相关结构和双向效应优先推荐 `mist-blue-terracotta-10`（雾蓝陶橙）。这是一项高权重偏好，不是机械绑定；模型因数据语义、对比或可读性改选时，必须返回 `palette_selection_rationale`。
- 热力图只能使用平台中的连续色板；不存在或类型不兼容的色板在模型输出验收时直接拒绝。
- 热力图、分面热力图、双向敏感性热力图和混淆矩阵的连续色条一律隐藏外轮廓及全部 spine，不允许出现右侧渐变色条黑框；该规则写入公共生成模板与 Studio 渲染器，不交给模型或人工判断。

## 全文图数控制

预算统计同时包含数据图与被保留的背景示意图、全文工作路线图等结构图。建议上限为 20：

- `<=20`：`within_recommended_budget`；
- `>20`：`requires_argument_pruning_or_explicit_exception`，自动正式落地被阻断；
- 保存计划的重执行只有在 `figure_budget_exception.approved_by_local_codex=true` 时允许超额，且该字段代表本地总编辑裁决，不能由规划模型自行批准。

20 是论文级编辑预算，而不是凑数目标。必要证据不足时可以少于 20；超过 20 时先审查语义重复、能否合并为表格或文字、是否真正推进后文建模决策。

## 为什么参考论文图 13 可以有三个子图

对 2025 年 C 题知网研学奖论文原 PDF 第 22 页的上下文与图面进行复核后，三个面板可以合并的理由是：

1. 三个面板分别对应 13、18、21 号染色体，比较维度只有一个，即“染色体”。
2. 三者共享孕周横轴、`|z|` 纵轴、阴性/阳性/可疑类别和阈值判别语义。
3. 图前提出的是一个统一问题：分类结果的判别边界是否在不同染色体上具有可比较的分离表现。
4. 图后需要进行跨染色体联合解释，尤其比较 21 号染色体在分布和协变量校正后的边界稳定性。

因此，这不是“把三张结果图节省成一个编号”，而是“同一证据问题下的三个同构分面”。若三个面板分别回答精度、敏感性和残差等不同问题，即使都来自同一模型，也不得合并。

## 组合图硬门槛

默认 `panel_count=1`。选择 2–3 面板时，规划项必须同时具备：

- `shared_reader_question=true`；
- `shared_axis_semantics=true`；
- `shared_legend_semantics=true`；
- 单一 `facet_dimension`；
- 非空 `panel_rationale` 与证据受限的 `joint_conclusion`；
- `panels` 数量与 `panel_count` 一致，并使用有意义的面板标题。

超过 3 面板直接拒绝。`faceted_heatmap` 模板还会根据运行时数据中的真实分组数二次检查，避免规划写 3、数据实际生成 5 个面板的绕过。
