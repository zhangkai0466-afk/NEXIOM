# 1.2.0 全文视觉论证升级说明

本次升级针对真实论文实测中“只生成少量结果图”的结构性原因，不以提高固定图数为目标。

## 已修复

- 扫描范围扩展到问题重述、本文工作、数据理解、预处理、建模、求解、验证、稳健性、评价和应用。
- 删除按 `fig01/fig02` 文件名分配问题的论文特定硬编码。
- 删除“一份数据最多一张图”的文件级去重；改为按“证据 + 视觉角色 + 读者问题”去重，同一文件可有互补视图。
- 删除“每批固定保留 2–4 张”和“选择少量图”的硬限制；以论证覆盖和独立信息增量控制数量。
- 新增领域解释、全文导航、预处理证明和单问复杂流程的结构性视觉机会扫描。
- 新增视觉主张字段：`visual_role`、`intended_claim`、`alternatives_considered`、图前任务、图后观察和建模推进。
- 新增 `evidence_gaps`，缺少处理前后、扰动或诊断证据时阻断强行绘图。
- 新增 `argument_coverage_ready` 与 `render_ready` 双门槛。
- 小型标签、图例、字号和边距问题继续由确定性规则与人工队列处理，不触发 AI 重绘。

## 图库扩充

- 可执行 Jinja2 模板由 31 个增至 40 个。
- 新增 ECDF、小提琴+箱线、散点+趋势、处理前后序列、阈值权衡、累计贡献、混淆矩阵、采样/参数轨迹、ACF。
- 案例模式由 1 条增至 11 条，增加使用前提、禁用情景和替代表达。
- 新增六篇 2023/2025 C 题论文案例注释，明确可迁移结论和不可过度推广之处。

## 仍然保持的边界

- 图库是“候选视觉语法库”，不是“题型—图形模板库”。
- 没有冻结数据或新实验结果时，不允许生成貌似合理的假图。
- 结构性概念图被判定为必要但尚未生产时，`argument_coverage_ready` 不得通过。
- MCP 不直接修改论文 LaTeX；最终落位仍由本地 Codex 总编辑完成。
