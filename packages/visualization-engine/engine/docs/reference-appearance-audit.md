# 科研绘图：逐图外观核验与三层图库设计

2026-09-09；已逐张查看文件夹32张截图，另记录本轮分组柱图附件。没有调用中转站模型，没有复刻截图数据。已识别不等于已渲染复现。

## 图库分三层，不把美化算成新统计方法

1. 基础图型：柱、直方图、散点、箱线、密度、曲线等；定义数据如何映射到图形。
2. 组合结构：分组、堆叠、分面、边际、原始点叠加、拟合/区间叠加；说明为何增加组件、共享什么数据和坐标。
3. 外观样式：浅填充深描边、渐变、点形、透明度、留白、轮廓和视角；保留统计语义，不凭美观加入未经计算的内容。

每个候选还必须具备读者问题、证据需求、计算方式、适用/禁用条件和渲染实现状态。外观参数来自审美平台配色及具体版面，不从压缩截图猜精确alpha。固定图名是检索入口，不是绘图决策终点。复合图不一定有唯一官方名称，宜记录标准组件及中英文别名。

## 核验发现

- 337是波长—幅值光谱/信号瀑布，不是概率密度。
- 331必须识别六边形分箱计数，不能仅说密度响应曲线。
- 330误差着色与348密度着色不是同一变体。现有预测模板仅按数据划分用固定色，已将这两个具体参考变体纠正为仅名词索引，并保留相近模板关系。
- 343没有足够证据证明组别代表有序策略强度；345不是共中心的分裂小提琴。
- 322与353属于同一组合家族，但组数和配色不同。32张截图不等于32种独立统计图型。
- 三维柱不要求必须交互；正文是否可用取决于真实数据适配、遮挡和印刷可读性。
