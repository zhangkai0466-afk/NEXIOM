# 模型供应商配置中心

版本：0.4.2，2026-09-19。当前实现以 [独立 Agent 运行边界](24-independent-agent.md) 为准。

## 配置与使用

NEXIOM 独立管理供应商名称、API 根地址、模型名称、认证方式和 API Key。新安装提供待配置的“NEXIOM API”，不读取本机 Codex 登录或默认模型。设置页支持新增、编辑、删除、切换、获取模型和测试连接；运行期间锁定供应商变更。

当前仅支持 OpenAI Responses 兼容服务。API 地址通常以 /v1 结尾，不要包含 /models 或 /responses。模型名称可以手动填写，也可以从接口返回的列表选择。Chat Completions、Anthropic Messages 和 Gemini 原生协议尚未接入，模型名称可填写不代表其协议已经兼容。

## 存储与运行

SQLite 只保存非密钥的供应商信息及修订号。桌面 API Key 由 Electron safeStorage 加密保存于 NEXIOM 应用目录；界面只读取是否已配置，保存后不回显。系统加密不可用时拒绝明文保存。浏览器开发环境只在核心进程内存中保存 Key。

运行只使用选中的 NEXIOM 供应商配置。引擎在 NEXIOM 专属目录启动，清除继承的个人 Agent 配置和认证环境变量，并禁用外部全局指令和自动项目指令注入。供应商 Key 作为本次运行参数传给引擎，不放进其工具 shell 的环境变量。不会读取或改写个人 Codex 配置。

每次运行保存供应商 ID、配置指纹、非密钥配置快照和运行参数。切换 A → B → A 可以恢复 NEXIOM 私有目录中未修改的 A 会话；修改供应商配置会增加修订号并启动新的模型上下文。API Key 不写入来源快照或指纹。

## 升级

旧版“本机 Codex 配置”被移除。升级保留明确填写的 API 配置与密钥，以及 NEXIOM 的项目和聊天展示，但清理旧引擎会话关联，避免续接个人 Codex 线程。旧聊天不会自动重新发送给模型；下次任务需要时重新提供背景。迁移只执行一次，之后新建的独立会话可正常续接。

## 连接检测的范围

“获取模型”和“测试连接”访问 GET <根地址>/models，验证网络、凭证与列表格式；Bearer 模式要求该供应商自己的 Key，无需认证模式不发送 Authorization。请求有 10 秒超时和 2 MB 响应上限，不跟随重定向。

检测通过不代表已经验证真实推理、流式、工具和上下文能力。缺少 /models 的服务目前无法通过检测，即使它实现了 /responses。厂商兼容性需要用自己的凭证完成真实任务验证。

## 开源与内核

NEXIOM 仍使用随应用分发的 Codex 开源引擎作为内部组件，不依赖个人 Codex 客户端、订阅登录或聊天目录。Claude Code 是可选后续内核，不是当前实现。本次修正解决的是应用边界与数据归属。
