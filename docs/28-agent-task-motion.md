# Agent 任务状态动效

所有 Agent 进行中指示统一使用九格呼吸与逐格柔光，文字为从左向右掠过的纯白扫光。九格维持已确认的 760ms 周期和各格相位；不旋转整个图标，不按固定计时伪造任务进度。

## 七种进行中状态

唯一配置位置：`apps/desktop/renderer/agent-task-state.ts` 的 `AGENT_TASK_STATES`。

| 状态 | 中文 | 颜色 | 实际事件示例 |
| --- | --- | --- | --- |
| thinking | 思考中 | 黄 `#ffa000` | reasoning、未收到具体工具活动 |
| reading | 阅读中 | 绿 `#20ad65` | 文件读取、项目资料读取 |
| analyzing | 分析中 | 红 `#ff6055` | 数据分析、验证、质量检查 |
| searching | 检索中 | 蓝 `#4b8dff` | 网页检索、搜索工具、rg |
| planning | 规划中 | 紫 `#a273ff` | 任务计划、图表方案规划 |
| executing | 执行中 | 橙 `#ff7c35` | 通用命令执行、渲染、未知工具 |
| writing | 编写中 | 青 `#12b8c9` | 答复流式输出、文件修改、内容生成 |

分类使用事件类型、注册工具名与命令入口，不扫描模型推理、工具参数或输出去猜测任务。并行活动优先显示当前轮最新运行项；历史项保留自己的任务类别。

“随便聊聊”在运行期间仅显示一处“思考中”与累计秒数，每秒更新，超过一分钟仍显示总秒数。答复、任务计划和工具卡片不重复显示进行中标签；任务结束后保留真实终态与耗时。

## 共用组件及终态

`AgentTaskStatus.tsx` 提供 `AgentTaskIcon`、`AgentTaskLabel`、`AgentTaskStatus`。普通对话、工具卡片、任务计划、赛题研读、附件分析、侧栏运行标记与外观预览复用同一实现。

进行中任务与终态独立：`running`、`completed`、`failed`、`cancelled`、`interrupted`。结束文案分别为“完成”“失败”“已停止”“已中断”；它们不增加新的进行中颜色。只有真实完成事件且没有错误才显示绿勾。完成时九格与对勾交叉淡入淡出，历史完成项直接显示终态，不重演运行过程。

普通文件加载、保存和导入的等待图标不属于 Agent 思考链，不在替换范围内。

## 可访问性与维护

- 任务状态同时提供中文文字，不仅依靠颜色区分。
- 应用“减少动态效果”、系统减少动态效果与高对比度均停用扫光和连续动画。
- 新任务优先映射现有七类；只有确认需要新的工作状态后才扩展集中注册表与测试。
- 生产状态由事件驱动；`output/playwright` 下时间轴只用于动画预览，不代表真实工作进度。
