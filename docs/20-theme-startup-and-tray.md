# NEXIOM 0.3.15：主题启动画面与托盘后台运行

日期：2026-09-19。

## 启动画面

主进程在创建窗口前读取 `appearance.json`，并用同一个解析结果设置原生窗口、
Windows 标题栏、HTML fallback 和 SVG 动画。上次选择浅色时使用 `#fafafa`
背景和深色图形；上次选择深色时使用黑色背景和白色图形；“跟随系统”在每次
启动时按当前 Windows 主题解析。

启动主题在 preload 阶段写入页面，优先于 renderer 的 localStorage 缓存。
动画中的 logo 遮挡层使用启动背景变量，mask 仍使用白色 alpha 笔画。原有透明
预热、首次绘制与有界显示兜底保留，动画在窗口真正显现后才开始。

标志两条飘带改为同一套严格几何网格。每条飘带由四条 `Δx=0` 的竖边和四条
`|Δx|=|Δy|` 的 45° 斜边交替组成，移除了旧路径中 1-3 单位的横向漂移。启动
动画 SVG、应用内 PNG、桌面 SVG/PNG/ICO 共用相同轮廓；定位、尺寸、mask 路径
和动画时序保持不变。

滑出的 `NEXIOM` 字标保持 `52px` 尺寸和既有字距，字重由 `300` 调整为 `400`，
改善细线感，同时不改变字标占位和动画节奏。

## 后台运行

Windows 托盘创建成功后，关闭按钮和 Alt+F4 仅隐藏窗口，不关闭 renderer、
Core 或正在运行的任务。托盘单击或菜单“打开 NEXIOM”、再次启动桌面快捷方式
都会恢复并聚焦同一个窗口，因此未发送的草稿和界面状态也会保留。

托盘菜单“退出 NEXIOM”才执行完整关闭：停止 Core、销毁托盘并退出应用。
如果托盘创建失败，关闭按钮仍正常退出，避免应用隐藏后失去恢复入口。系统结束
会话及 Core 已异常退出时，明确退出也不会被关闭拦截器阻止。

## 验证

- 浅色、深色和跟随系统的原生冷启动连续采样均与保存主题一致。
- 浅色动画为深色 logo/字标，深色动画为白色 logo/字标；动画结束后主题不跳变。
- 字标在浅色与深色预览中计算字重均为 `400`，尺寸仍为 `52px`，无横向溢出。
- 两个顶部尖角在 SVG 中均为单点，全部竖边保持平行，并在 100%、125%、150%
  缩放下连续展开；180ms 至 1320ms 的关键帧没有缺口或闪烁。
- renderer 缓存与 `appearance.json` 不一致时，主进程保存主题胜出。
- 原生 Alt+F4 后 BrowserWindow 仍存在但隐藏，Core 与 renderer PID 保持不变；
  再次启动后窗口恢复、同一 PID 继续且草稿保留。
- 最小化后再次启动会 restore；明确退出后所有测试进程退出。
- 模拟 Core 先异常退出后，明确退出仍以状态 0 完成。
