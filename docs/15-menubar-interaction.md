# 0.3.6 顶部菜单交互

原来的“文件”和“视图”使用两个独立的 details，连续点击会同时展开；除设置入口外，执行选项也没有统一收起菜单。

改为 ChromeMenuBar 单一展开状态，同一时刻只显示一个菜单。未展开时悬停只高亮，点击打开；已展开时，鼠标移到另一个标题直接切换。悬停切换后的首次点击确认当前菜单，不会因 pointerenter 与 click 连续触发而误关闭；重复点击当前标题关闭。

执行选项、点击内容区外部、Escape、焦点移出、窗口失焦或页面隐藏均收起菜单。选项执行前先把焦点移回菜单标题，确保从设置返回后焦点仍有效。标题和选项支持方向键、Home/End、Enter/Space、Tab；Escape 返回标题，外部点击不抢回焦点。

构建和桌面交互验收脚本：`output/playwright/menu-interaction-check.cjs`。覆盖浅色和暗色下的连续点击、悬停后点击、返回当前标题、外部点击、键盘遍历、选项执行、弹窗、设置返回与焦点离开。Playwright 持续模拟焦点，失焦关闭单独通过派发浏览器 blur 事件检查，不将其声称为原生 Alt+Tab 验收。结果与截图保存为 `output/playwright/menu-0.3.6-*`。
