# NEXIOM 0.3 桌面交付

日期：2026-09-18。

## 可运行入口

- 桌面快捷方式：系统 Desktop 目录下的 `NEXIOM.lnk`。
- Windows x64：`release/NEXIOM-0.3.0-win-x64/NEXIOM.exe`，启动不依赖开发服务器。
- 快捷方式建立脚本：`scripts/create-shortcut.ps1`，检查目标程序与图标后创建或更新，不影响其他软件快捷方式。
- EXE 包含 NEXIOM 图标、ProductName、FileDescription 和 0.3.0 版本资源。
- 本版仍为未签名便携目录，需要保留全部文件；尚不是安装器或自动更新发行渠道。

## 界面与输出

根据用户提供的 Codex 暗色截图，重建主题变量、窗口栏、侧栏密度、会话宽度、消息层级和圆角输入区。采用 Segoe UI Variable / Segoe UI / Microsoft YaHei UI 系统字体，正文默认 15px，可在设置调整至 13-18px；图标统一使用 Lucide。没有缩放正文、模糊正文或以图片代替文字。

提供暗色、浅色、跟随系统，设置持久化并同步原生窗口按钮背景。浏览器预览同样支持主题；桌面以宿主保存的主题为准。

输出由 Codex 原生文本增量驱动，历史消息不进行逐字重播。模型返回的公开分析摘要可折叠，命令与文件记录可展开，Markdown、表格、代码、数学公式和项目文件链接可直接审阅。Claude Code 的流式反馈是交互参考，未复制其品牌或未获授权实现。

Thinking Orbs 用于真实任务状态；Motion 用于工具展开；侧栏、弹窗和按钮使用短过渡。遵守系统减少动态效果偏好，并提供独立开关。用户向上阅读时暂停自动跟随，新任务提交时回到当前进展；提供回到底部入口。

## 核心与记忆

核心细节见 [0.3 核心升级](09-agent-core-upgrade.md)：原生工具循环、线程续接、自动压缩、真实上下文统计、可编辑项目记忆及 schema3 迁移。项目记忆位于 `.nexiom/MEMORY.md`，内容由用户保存，保存后在下一轮加载，使用版本检查防止静默覆盖。

上下文窗口、上次输入/输出和缓存 token 来自引擎实际事件。累计消耗与最近请求分开，不以累计消耗显示窗口占用率。未知指标标为未知。

## 本次验收

- 22 项自动测试与 TypeScript / 生产构建通过；增加真实增量、公开摘要边界、压缩事件、记忆冲突、工具输出脱敏结构及任务用量累计回归。
- 真实 Codex 生成并运行 Python 最小二乘实验，外部验证斜率 2、截距 1、RMSE 0；一次运行观察到 126 次原生文本更新，浏览器另观察到 103 个不同的流式文本长度。
- 完全关闭 Core 后恢复同一原生线程，准确使用历史结果和项目记忆；旧 SDK exec 创建的线程迁移到 app-server 也已实测。
- 真正启动 Python 等待任务后取消，确认其进程退出。
- 桌面打包版以 1360x900、DPR 1.25 验证；CDP 实际字体为 Microsoft YaHei UI 和 Segoe UI Variable，无宋体/Times 回退。
- 暗色、浅色、系统主题以及 36px 原生标题栏同步通过；项目、记忆、加密 API Key 重启恢复通过；执行确认取消未产生任务；无页面异常。
- 浏览器 1440x960 和 390x844 验证无页面横向溢出，图片资源正常，数学公式、文件预览和工具展开可用。
- Thinking Orbs 可见状态经两帧像素变化确认在运动；开启减少动态效果后像素保持不变。
- 实际输出截图及录屏位于 `output/playwright/`。动画已实测工作，但没有把一次运行声称为所有设备上恒定 60fps 的性能保证。

## 后续边界

此次使用 Codex，尚未增加 Claude 引擎切换。自动压缩有原生协议覆盖，但本次短任务未触发真实长上下文压缩。自定义模型服务尚未逐家实测。手动压缩、历史分叉、自动长期记忆提炼、实验版本与论文证据管理、论文导出、自动更新仍待实现。

网页检索、许可证核验和五个数学/科学 Agent 项目的独立取舍见 [研究文档](08-design-agent-research.md)；这些研究目标不等于全部已经实现。
